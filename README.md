## Update an existing resource

1. Edit the root `index.html` to change its description, card, or links.
2. Edit the resource’s viewer file to change its presentation URL or browser tab title.
3. Commit the changes to the branch configured for GitHub Pages.
4. After deployment, check the homepage, presentation loading, fullscreen, and copied links.

Keep homepage navigation and sharing links aligned with the viewer’s published address.

## Add a resource

1. Create a folder with a short, descriptive name.
2. Add an `index.html` viewer inside that folder.
3. Add a corresponding card to the homepage.
4. Update the card’s description, identifiers, open links, and share link.
5. Publish and verify the new resource.

## Ownership

This repository manages the homepage and presentation viewers. The underlying presentations remain with their respective owners.
